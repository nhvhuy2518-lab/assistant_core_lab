## Which path would you ship for policy questions, and why?

For handbook and student-service questions, I would choose the retrieval path because it can find relevant information from official documents and cite its sources. In my 25-question evaluation, retrieval and the LLM stub both answered 17 questions correctly, compared with 8 for the deterministic path. I would improve the privacy guardrails first because some questions about other students' private information were not correctly refused.

## H2 — Reflection

1. RAG works like an open-book exam where an assistant searches documents before answering a question.
2. The search engine finds the most relevant paragraphs from the knowledge base.
3. The language model uses those paragraphs to generate an answer.
4. Our Python code checks whether the answer cites only sources that were actually retrieved.
5. If the documents do not contain reliable information, the assistant should say "I don't know" instead of guessing.
